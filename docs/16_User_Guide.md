# 16. User Guide

## For Administrators
1. Log in with admin credentials.
2. Approve pending faculty at the top of the dashboard.
3. Select a Degree Program, create a Batch.
4. Upload an Excel file with students or add them manually.
5. Create a Semester and add Subjects, assigning them to approved faculty.
6. Click "ENROLL ALL BATCH STUDENTS".
7. Click the "Analytics" button next to any subject to view performance.

## For Faculty
1. Register an account and wait for Admin approval.
2. Log in and view your assigned subjects.
3. Click "Marks Entry" to input and save marks.
4. Click "View Analytics" to see interactive graphs of your students' performance.
