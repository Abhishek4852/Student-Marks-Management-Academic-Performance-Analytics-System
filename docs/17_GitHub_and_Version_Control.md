# 17. GitHub and Version Control

- **Branching Strategy**: `main` for production, `dev` for development.
- **Gitignore**: Excludes `venv/`, `node_modules/`, `db.sqlite3`, `.env`, and `__pycache__/`.
- **Commit Messages**: 
  - `feat: added analytics endpoint`
  - `fix: resolved constraint error on marks model`
  - `docs: updated SRS`
