# 2. Problem Statement

## Background
Academic institutions handle thousands of student records, subject assignments, and marks entries every semester. Traditional methods involve transferring data between Excel sheets and physical ledgers.

## The Core Problem
Administrators struggle with batch creation, bulk student onboarding, and assigning faculty to subjects without overlaps. Faculty members struggle with securely entering marks and tracking their students' performance trends across multiple internal tests. 

## The Solution
A unified, role-based web application that streamlines the entire academic lifecycle—from student enrollment to final marks analytics. By leveraging an Object-Oriented design and a layered architecture, the system guarantees data integrity, security, and scalability.
