# 9. UI Wireframes & Design

## Layout Structure
- **Sidebar/Header**: Navigation based on user role (Admin vs Faculty).
- **Content Area**: Dynamic views built with React Router.

## Key Screens
1. **Login**: Username, Password, Login Button, Register Link.
2. **Admin Dashboard**:
   - Top: Pending Faculty Approvals.
   - Middle: Batch creation & Selection.
   - Split Panel: Manual Student Entry (Left) | Excel Bulk Upload (Right).
   - Bottom: Semester Creation & Subject Assignment.
3. **Faculty Dashboard**:
   - Grid of Assigned Subjects.
   - Tabs for "Marks Entry" (Table with inputs) and "View Analytics" (Recharts Bar Chart).
